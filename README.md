# 磁力链接悬浮预览用户脚本

## 功能概述
本脚本为浏览器用户脚本，可在支持的网页中自动检测磁力链接并在链接旁添加悬浮预览功能。通过点击或悬停磁力链接，可快速查看链接的详细信息（如文件名、类型、大小、截图等），提升磁力链接浏览体验。

---

## 主要功能
1. **自动检测磁力链接**  
   自动识别网页中的磁力链接（`magnet:?xt=urn:btih:...`）或40位十六进制特征码。
   
2. **悬浮预览**  
   - 鼠标悬停或点击磁力链接旁的磁铁图标（🧲），显示链接详情。
   - 包含文件名、类型、文件大小、文件数量等信息。
   - 支持显示链接关联的截图预览（若存在）。

3. **图片放大预览**  
   - 点击预览中的截图可进入全屏放大模式。
   - 支持左右滑动切换截图（或使用键盘方向键）。
   - 点击空白处或按 `Esc` 键关闭放大视图。

4. **本地缓存机制**  
   自动缓存已查询的磁力链接信息，默认缓存有效期为1天，减少重复请求。

## 安装指南

2. 打开 [Greasy Fork 安装页面](https://update.greasyfork.org/scripts/544637/Whatslink%E7%A3%81%E5%8A%9B%E9%A2%84%E8%A7%88.user.js)。
3. 点击 "安装此脚本" 按钮。

## 使用说明
1. **访问支持的网站**  
   当前支持的网站包括：
   - `6v520.com`
   - `javdb.com`
   - `javbus.com`
   - 其他任意网页（通过 `@match *://*.*/*`）。

2. **触发悬浮预览**  
   - 鼠标悬停或点击磁力链接旁的磁铁图标（ℏ）。
   - 若链接已缓存，预览将立即显示。

3. **选中文本中的磁力链接**  
   在网页任意位置选中磁力链接或40位特征码，脚本会在选区旁显示磁铁图标并触发预览。

4. **操作放大图片**  
   - 点击预览截图 → 进入全屏放大模式。
   - 左右滑动或按方向键切换截图。
   - 点击空白处或按 `Esc` 键关闭放大视图。

---

## 注意事项
1. **权限需求**  
   - 需允许跨域请求（`@grant GM_xmlhttpRequest`）以获取磁力链接信息。
   - 需访问本地存储（`@grant GM_setValue`/`GM_getValue`）以实现缓存。

2. **兼容性**  
   - 仅支持现代浏览器（Chrome/Firefox/Edge）。
   - 部分网站可能因反爬机制导致请求失败。

3. **缓存管理**  
   - 缓存数据存储在浏览器本地，可通过脚本管理器清除。
   - 默认缓存有效期为1天，可通过修改 `cacheTTL` 参数调整。

## 常见问题
**Q：为什么磁铁图标没有显示？**  
A：可能因以下原因：
- 链接格式不完整（非标准磁力链接）。
- 脚本未加载成功（刷新页面重试）。
- 网站启用了反爬机制（尝试其他网站）。
